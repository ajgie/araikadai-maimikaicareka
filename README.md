
# 🎀 My E-Portfolio | แฟ้มสะสมผลงานออนไลน์

เว็บไซต์แฟ้มสะสมผลงานอิเล็กทรอนิกส์ (E-Portfolio) สำหรับนักเรียนที่ต้องการนำเสนอประวัติส่วนตัว ความสามารถ ผลงาน และกิจกรรมต่าง ๆ เพื่อประกอบการสมัครเข้าศึกษาต่อในระดับมหาวิทยาลัย

## ✨ Features
- หน้าแรก (Home)
- แนะนำตัว (About Me)
- ผลงาน (Portfolio)
- กิจกรรมและประสบการณ์ (Activities)
- ปุ่มเชื่อมต่อ GitHub
- Responsive รองรับคอมพิวเตอร์และโทรศัพท์มือถือ
- เมนูนำทางพร้อม Animation

## 🎨 Design
- Theme: Pastel Pink & White
- Style: Korean Minimal
- Font: Prompt
- Modern & Responsive Design

## 💻 Technologies
- HTML5
- CSS3
- JavaScript

## 🚀 How to Use
1. ดาวน์โหลดหรือ Clone Repository
2. เปิดไฟล์ `index.html` ผ่าน Web Browser
3. แก้ไขข้อมูลส่วนตัว ผลงาน และกิจกรรมตามต้องการ

## 🌐 Website Deployment
เว็บไซต์สามารถเผยแพร่ผ่าน GitHub Pages ได้โดยไม่ต้องติดตั้งเครื่องมือเพิ่มเติม

1. เข้า Settings ของ Repository
2. เลือก Pages
3. เลือก Deploy from a branch
4. เลือก Branch: main
5. เลือก Folder: / (root)
6. กด Save

## 📌 Purpose
จัดทำขึ้นเพื่อรวบรวมและนำเสนอข้อมูลส่วนตัว ประวัติการศึกษา ความสามารถ ผลงาน และกิจกรรมต่าง ๆ ในรูปแบบเว็บไซต์ออนไลน์ สำหรับใช้ประกอบการสมัครเข้าศึกษาต่อระดับมหาวิทยาลัย
